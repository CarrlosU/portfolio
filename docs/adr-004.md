# ADR-004 — Sistema de diseño Dark Tech

- Estado: Aceptado
- Versión: 1.0

## 1. Tokens (`src/styles/tokens.css`)
```
--bg #09090B, --surface #15151B, --surface-2 #1C1C22
--primary #6C3BFF, hover #5A2FE0
--text #FAFAFA, --muted #A1A1AA, --border #27272A
radius 12px, max-width contenido 72rem (1152px), para TV no estirar infinito.
```

## 2. Principios
- Minimalista premium, no plantilla CV. Jerarquía clara, espacios amplios, sin animaciones pesadas.
- Tipografía: Geist/Inter, `antialiased`. Contraste AA mínimo.
- Componentes: cards `surface + border + radius`, chips tech, botones primario/secundario, sección con eyebrow + título + grid.
- Iconografía Lucide solo. Sin emojis en UI.
- Animaciones: Framer Motion solo `opacity/transform`, respetar `prefers-reduced-motion`, lazy para pesados.
- Imágenes: `unoptimized` (export), lazy excepto hero, WebP/AVIF cuando haya fotos reales.

## 3. Responsive
- Mobile-first. Breakpoints Tailwind estándar: base, sm 640, md 768, lg 1024, xl 1280, 2xl 1536.
- Mínimo obligatorio 320px funcional. 280-319 progresivo. <280 fuera de alcance.
- Matriz de prueba: 320, 360, 390, 430, 768, 1024, 1280, 1440, 1920, 2560, 3840.
- TV: mismo layout con `max-width`, tipografía legible a distancia, sin elementos diminutos, sin nav por control remoto en v1.
- Cero overflow horizontal (test automatizado `scrollWidth <= clientWidth`).

## 4. Accesibilidad
Landmarks (`header/main/nav/footer`), h1 único, foco visible, labels, contraste, teclado completo, `alt` descriptivos.

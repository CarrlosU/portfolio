# ADR-005 — Exportación estática y despliegue

- Estado: Aceptado
- Versión: 1.0

## 1. Build
```ts
// next.config.ts
{ output: "export", trailingSlash: true, images: { unoptimized: true } }
```
- Sin API Routes, Server Actions, middleware dinámico, ni `next start` en prod.
- `npm run build` -> `out/` (HTML/CSS/JS + `sitemap.xml`, `robots.txt`, CV PDFs).

## 2. Git
- Remoto único: `https://github.com/CarrlosU/portfolio.git`, rama `main`.
- Flujo: `feature/portfolio-v1` -> PR -> `main`. No push directo incompleto.
- Quality Gate obligatorio antes de push (ver plan QA): TS 0 errores, ESLint 0, build OK, Vitest+RTL OK, Playwright Chromium+Firefox+WebKit OK, screenshots revisadas, Lighthouse ≥90/95, sin secretos en diff.

## 3. Render
- Static Site sobre `CarrlosU/portfolio@main`.
- Build: `npm ci && npm run build` — Publish: `out/`.
- Cuenta Render debe estar vinculada a `CarrlosU` (no a `CarlosUrregoJ`).
- HTTPS + CDN + auto-deploy. Dominio custom después.

## 4. QA mínimo pre-push
`typecheck, lint, test:unit, test:components, build, test:e2e, test:visual, lighthouse`. Servir `out/` con servidor estático para E2E final, no asumir `next start`.

## 5. Rollback
Cada deploy es un commit en `main`. Revert = revert commit + push + redeploy automático.

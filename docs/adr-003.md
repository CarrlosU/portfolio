# ADR-003 — Internacionalización y routing

- Estado: Aceptado
- Versión: 1.0

## 1. Decisión
Rutas por locale, sin depender de `localStorage` ni redirects dinámicos (incompatible con `output: export`).

| Recurso | ES | EN |
|---|---|---|
| Home | `/es/` | `/en/` |
| Proyecto | `/es/projects/[slug]/` | `/en/projects/[slug]/` |
| Raíz `/` | Landing con selector ES/EN | — |

## 2. Implementación
- `src/app/[locale]/layout.tsx` + `page.tsx` + `[locale]/projects/[slug]/page.tsx`
- `generateStaticParams()`: 2 locales + 8 combinaciones proyecto-idioma.
- Contenido Server Components; selector idioma Client Component pequeño (`<Link href=/en/...>`).
- `generateMetadata` localizado + `hreflang`, canonical, OG por idioma.
- Diccionarios tipados: `src/content/es|en/*.ts` + tipos `Localized<T>`. Prohibido strings sueltos en UI.
- `defaultLocale = 'es'`. `/` no redirige automáticamente (export estático), muestra ambas opciones.

## 3. Reglas
- Toda UI visible debe pasar por diccionario o campo `Record<Locale, string>`.
- El cambio ES<->EN conserva la ruta equivalente (mismo slug).
- 404 localizado.
